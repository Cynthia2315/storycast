About + access

StoryCast is built to make storytelling more open, calm, and inclusive

We design each page as a clear path into the story, with support for transcripts, captions, keyboard navigation, and screen readers so the content stays useful even when the medium changes.

Mission

A research-driven structure that keeps people oriented

The information architecture follows a simple pattern: introduce the platform, move into a specific story, then explain the access model and how to participate. That keeps the navigation predictable for both new and returning visitors.

StoryCast uses editorial pacing, strong hierarchy, and flexible media layouts so the experience feels intentional on desktop and mobile. The visual design stays calm and warm while the interaction model keeps controls obvious.

The result is a microsite that works as a content showcase, a design system example, and an accessibility-first reference.

Accessibility features

Designed around WCAG AA fundamentals

These patterns are visible in the markup, the layout, and the media treatment so the experience remains navigable and readable for a wide range of users.

T

Full transcripts

Audio stories include full transcript files and in-page transcript sections with speaker labels.

CC

Closed captions

Video stories include caption tracks so spoken content is available without sound.

KB

Keyboard navigation

All interactive controls remain reachable and visibly focused with the keyboard alone.

SR

Screen reader support

Semantic landmarks, descriptive labels, and meaningful structure reduce guesswork.

AA

WCAG 2.1 AA contrast

The navy, coral, and light background palette is tuned for accessible contrast relationships.

HI

High contrast design

Focus states, button treatment, and type sizing stay legible across breakpoints.
